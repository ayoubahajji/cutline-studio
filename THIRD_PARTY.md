# Third-party components

The application source is licensed under MIT. It contains no bundled CapCut code, proprietary assets, or customer footage.

## Runtime tools installed separately

- **FFmpeg**: local source checks, audio/video processing, and MP4 encoding. No FFmpeg executable is distributed here. FFmpeg builds have their own licensing and codec configuration; consult the license information for the build you install.
- **whisper.cpp and speech models**: optional local transcription. Neither executable nor model weights are distributed here. Model and tool licenses are separate from this repository.
- **Your browser and Python**: installed separately.

## Development dependencies

`jsdom` is a test-only npm dependency. Its license and its transitive dependencies' licenses are included in their installed packages. `package-lock.json` pins the dependency graph. Production use requires no npm packages.

Users supply their own media and are responsible for permission to use or share it. The default sample landscapes and sound beds are generated by the app.
